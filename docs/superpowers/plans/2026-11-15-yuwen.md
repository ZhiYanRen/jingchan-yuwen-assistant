# 静婵语文小助手 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans. 用户要求直接做，本会话连续实施，不再设计确认；遵守AGENTS.md在main开发并发布。

**Goal:** 可实际使用并发布的人教统编版小学六年级上下册听写、积累与错题复习应用。
**Architecture:** 原生HTML/CSS/ES modules；静态JSON课程，localStorage个人状态，浏览器语音，无生产API。构建只复制public到dist并生成版本化缓存清单。
**Tech Stack:** Node22+本地构建/测试；Playwright浏览器验证；sharp开发时生成图标。
**Spec:** DESIGN.md、UX-CONTRACT.md、SOURCES.md（内容核对过程中建立）。

## Global Constraints
- GitHub Pages静态子路径，main单公开仓库；不创建分支/worktree。
- 上册采用2024审核修订目录；下册标注官方可核验版本，不声称已确认2024修订；两册与五四制区分；不发布整本教材或现代课文全文。
- 本机数据与公开内容分离，备份验证后确认替换。
- iPad优先、手机PC、44px触控、减少动态效果、键盘。

## Review Focus
- 损坏存储与超限备份不能覆盖原记录。
- 语音不可用/中断与刷新不泄露答案或丢断点。
- 上下册课号/单元与略读拓展词的归属正确。
- 连续点击核对不重复记分，切换导航取消语音。
- 子路径、离线缓存、更新不能加载混合版本。
